# Repository guide

The active project is **`texntailor/`**, the Tex N Tailor website (Astro + three.js).
Read `texntailor/CLAUDE.md` (rules and commands) and `texntailor/HANDOFF.md` (full history and open items) first.

Other folders are unrelated earlier experiments. Leave them untouched unless asked:
`meliz/` (a gifting site, Next.js; the root `netlify.toml` still builds it) and the root
`index.html`/`calculator.js`/`style.css` (a calculator).
